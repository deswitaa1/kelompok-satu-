## 2. Project Title

Personal Budget Calculator

---

## 3. Project Description

This program is a simple personal budget calculator that helps user calculate their total income, expenses, and remaining budget.

---

## 4. Objectives

This project is designed to apply the following programming concepts:

- Variables
- Data types
- Operators
- Conditional statements
- Loops
- Algorithms
- JavaScript

---

## 5. Input

The program receives:

- The user's income
- The number of expenses
- The expenses category
- The amount of money spent

---

## 6. Process

The program calculates the total expenses and remaining balance.

The program then determine the user's financial condition based on the remaining balance:

- Balance > 30% of income → Good
- Balance 10%-29% of income → Needs Attention
- Balance < 10% of income → Critical

---

## 7. Output

The program displays:

- Total income
- Total expenses
- Remaining balance
- Financial condition
- Budget summary
